# LocalType 产品方向

LocalType 的定位是“面向中文和中英文混合用户的本地智能语音键盘”。体验参考 Typeless，但默认离线，并将开发者场景、隐私和 AI 修改的可控性作为核心差异。

## 产品原则

1. **说得自然**：允许停顿、重复、口误和中途改口。
2. **写得清楚**：自动断句、去除无意义语气词并做保守纠错。
3. **用得放心**：音频和文本默认只在本机处理。
4. **修改可控**：同时提供智能模式和原文模式；校对风险过高时回退原文。
5. **终端安全**：保护命令、路径、数字、大小写和专有名词，只输入、不执行。

## Typeless 听写浮层参考

对 [Typeless Dictate 教程](https://www.typeless.com/help/quickstart/dictate) 及其官方桌面演示视频的逐帧观察显示：录音态使用屏幕底部居中的黑色胶囊，左右分别为取消和完成，中间为动态波形；临时识别文本在其上方的蓝色圆角卡片中增长，不直接反复修改目标输入框；停止后文字卡片消失，胶囊收缩为 `Thinking`，最终只向目标应用提交一次整理结果。

LocalType 复用这套状态层级而非逐像素复制：浮层跟随当前显示器，录音态展示取消/波形/完成，临时文本使用独立蓝色卡片，处理态收缩为 `Polishing…`。Wayland 窗口不取得键盘焦点，透明区域保持 click-through；普通输入框在安全 preedit 接入前仍只接收一次最终文本。

## Omarchy MVP

当前 0.7 版本包含 vLLM 流式本地推理、PipeWire 录音、Hyprland 全局快捷键、用户级 systemd 服务、底部居中的听写浮层、Omarchy Shell 状态组件、声学纠错记忆，以及一套原生 Omarchy 桌面应用。听写浮层参考 Typeless：录音时显示取消、动态波形、可回滚临时文字和完成控制，停止后收缩为本地处理状态；窗口不抢键盘焦点，透明区域不拦截下层应用输入。开始、处理和完成的常规桌面通知由浮层取代，错误仍保留通知。独立的 `partial_text` 状态离开录音阶段即清除，不能进入历史或学习闭环。桌面端已经覆盖工作台、听写历史、图形化个人词典、应用场景、本地模型状态和设置，并自动继承 Omarchy 主题。界面、状态面板与通知默认使用英文，可切换简体中文；智能听写和原文听写快捷键均可自定义。

录音中链路为：500 ms PCM 块 → Qwen3-ASR/vLLM 原生 streaming state → 可回滚临时文字 → 底部浮层。停止后不复用临时结果，而是执行：完整 WAV + 个人规范词上下文 → 最终 Qwen3-ASR → 精确/拼音/字形候选召回 → 可选的声学样本 DTW 确认 → 单次 Qwen3-0.6B 语境纠错与保守校对 → 内容保真检查 → 当前应用唯一提交。个人词汇不再做无条件全局替换；普通应用使用 `wtype`，终端使用单次 bracketed paste。

声学学习是显式开启的本地功能：循环暂存最近 20 条录音，用户纠错后由 Qwen3-ForcedAligner 提取对应字段，只长期保留短词语样本和声学特征。音频证据必须与文本/拼音候选共同命中，不能单独触发替换；真正同音词仍交给整句语义判断。

## 路线图

- **0.1 Omarchy MVP**：一键安装、智能/原文听写、状态面板、词典、自检与安全卸载。
- **0.2 Omarchy 桌面应用**：应用级规则、图形化词典、模型状态、听写历史和主题联动。
- **0.3 双语与个性化**：默认英文、可选简体中文、可自定义快捷键。
- **0.4 Omarchy 完整体验**：模型切换、录音悬浮反馈、撤回与更完整的场景自动匹配。
- **0.5 跨平台准备**：简化核心信息架构与稳定本地数据契约。
- **0.6 声学纠错记忆**：时间戳对齐、词语音频样本、文本与 DTW 声学证据融合。
- **0.7 流式听写（当前）**：vLLM streaming state、实时浮层预览、句尾回滚与最终唯一提交。
- **0.8 原生输入法预编辑**：Fcitx5/Wayland preedit，把临时文字安全显示在目标输入框。
- **1.0 桌面产品**：macOS、Windows 正式支持，Linux Beta，可选同步与云推理。

跨平台版本应把录音、全局快捷键、当前应用识别、文字注入、权限和推理解耦为稳定接口；Omarchy 版本继续作为 Linux 产品验证和模型效果实验场。
